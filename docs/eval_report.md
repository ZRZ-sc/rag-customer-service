## 五、评测口径说明

- **意图识别准确率**：仅统计评测集中标注了 `intent` 且返回 200 的轮次
- **答案正确率**：`source` 相符 且 关键词断言通过 且 反向断言通过 且 改写断言通过
  - `must_contain` 要求全部命中；`must_contain_any` 任一命中即可（规避 LLM 措辞差异）
  - 多轮追问额外校验 `rewritten_contains`（指代消解后应带订单号）与 `rewritten_not_contains`（政策护栏不应注入订单号）
- **HTTP 状态符合率**：覆盖 401（鉴权）/403（越权）/404（实体不存在）/422（参数非法）等异常路径
- 未标注内容断言的用例（闲聊、乱码等）仅以 HTTP 状态判定其正确性
- **延迟**：服务端 `latency_ms`（含缓存命中与冷启动混合分布），客户端往返含网络与 Python 序列化开销
- 评测前默认清空评测问题的**答案缓存**，确保测的是真实生成而非历史缓存
